# Roadmap реализации

1. Согласовать исходные данные предприятия и ограничения эксплуатации.
2. Создать проверяемую термодинамическую конфигурацию для MEG/DEG/TEG.
3. Воспроизвести сходящийся поток DWSIM для традиционной или Petlyuk-эквивалентной схемы.
4. Проверить материальный и тепловой баланс независимой расчётной методикой.
5. Сравнить традиционную схему и DWC по единым критериям.
6. Подготовить конструкторские листы и расчёт прочности в рамках доступной проектной документации.
7. Согласовать стендовые испытания, методику, измерения и протоколы.
8. Обновить статусы только после появления подтверждающих файлов.
