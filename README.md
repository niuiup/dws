# DWC Digital Twin — Demo

Статическая русскоязычная демонстрация концепции колонны с разделительной стенкой для разделения MEG, DEG и TEG. Интерактивная схема, сравнение с традиционными двумя колоннами и упрощённый массовый баланс работают в браузере; серверная часть и сборка не нужны.

> Калькулятор — упрощённая оценка для демонстрации, а не строгая термодинамическая симуляция. Показатели потенциальной экономии приблизительны и основаны на литературных оценках.

## Запуск локально

Из корня репозитория запустите:

```bash
python -m http.server 8000 --directory web-demo
```

Откройте <http://localhost:8000/>. Остановка сервера: `Ctrl+C`.

## Публикация через GitHub Pages

1. Добавьте и отправьте папку `web-demo/` в репозиторий на ветку `main`.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Сохраните настройки и дождитесь публикации.

Для публикации из корня репозитория URL страницы будет иметь вид `https://<user>.github.io/<repo>/web-demo/`. Выбор `/docs` вместо корня публикует только содержимое папки `docs`; чтобы использовать этот вариант, разместите копию демо в `docs/web-demo/`. Файл `.nojekyll` добавлен в демонстрационную папку, чтобы отключить обработку Jekyll.

## Содержимое

- `index.html` — структура страницы и русскоязычный интерфейс.
- `css/style.css` — адаптивная тёмная тема и оформление SVG-схемы.
- `js/calculation.js` — простая оценка продуктовых потоков и экономии.
- `js/visualization.js` — схема, вывод результатов и сравнительный график Chart.js.
- `js/main.js` — связь элементов интерфейса, проверка ввода и генерация отчёта.

График загружает Chart.js с CDN; при недоступности CDN страница показывает текстовую сводку вместо графика.
