# Методология расчётов

## Существующий демо-калькулятор

`js/calculation.js` выполняет упрощённый материальный баланс:
- извлечение целевого компонента принимается равным 98%;
- продуктовый поток определяется по целевой чистоте;
- примеси распределяются пропорционально входным потокам остальных компонентов;
- потенциал экономии задаётся фиксированными демонстрационными коэффициентами.

Это не термодинамический расчёт, не расчёт тарелок, гидравлики или аппарата. Результаты не могут использоваться для проектирования.

## Подтверждённая методика

Строгая методика DWSIM ещё не утверждена. При появлении расчёта должны быть зафиксированы:
- база данных и термодинамическая модель;
- допущения, число стадий и условия определения;
- начальные значения;
- критерии сходимости;
- независимая проверка потоков и балансов;
- ссылка на расчётный файл и протокол.
